# R1 有界集合中心逼近

动机：旧算法为了20度交角，可能先远离目标方向横向移动，再折回清除。题面并不要求固定交角。以首次有信号的1500米上界和公开1800米圆域初始化保守多边形，每次到方位对齐包围盒的中心测量，再用新方位楔收缩。

本轮核心变化是主动定位流程。保持七站扫描、16源/逐频道七站停止、旧未缓存第二点的任务入口评分；因新流程不存在旧二点缓存，旧共享暂不接入，此差异必须由后续共享机制消融解释。每步检测先核对所有多边形顶点在1000米内，最终所有顶点在20米内才作证书清除。至多16次中心测量，停滞时回退有限28米网格。

无数值搜索。理论：保守半平面交保留真源；凸圆包含全部顶点则包含整个多边形。外切正32边形近似接收圆与区域圆，不能使用内接多边形。逼近收敛速率尚不声称严格浮点证明，有限光学回退保障终止。完整流程时间为实验结论。
