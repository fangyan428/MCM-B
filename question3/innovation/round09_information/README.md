# R9 对所有可能读数的观测价值门控

R4在每个合格位置对其他目标都检测，可能付费获得很少的新信息。R9按可行集合和所有可能示向度，证明一次共享观测足以把覆盖半径减半或进入20米终端域，才执行该共享检测。

可能示向度区间被完整分成16个角度段；每段用“误差半宽+段半宽”的放宽楔覆盖该段所有可能输出，与原集合相交后计算覆盖半径上界。这是保守区间覆盖，不是用16个假源点当真值抽样。存在任何段无法满足收缩门槛即跳过。16是数值证书划分精度，不做精度扫描；减半对应二分收缩的一个信息层级，不扫描其它门槛。

GATED_TOUR_SHARED_PARALLAX对照TOUR_SHARED_PARALLAX；其余动作、调度及停止机制不变。跳过检测只放弃信息，不删除任何候选源，因此不会破坏原清除保证。是否减少整局时间属于实验问题。
