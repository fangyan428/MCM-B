# R2：按真实剩余瓶颈再检验机制

R1独立验证48布局×4误差×2舍入，7臂2688局全部清除且审计通过。暂选父组合ADAPT_GATED均值改善1.222%，布局分层bootstrap95%区间[0.363%,2.065%]，P95反而上升1.226%；其共享门控相对ADAPT_SHARED只省0.0021%。中心直进慢0.879%，单项尺度视差改善0.843%，pair共享改善0.386%，pair门控共享改善0.391%。这支持继续一次有明确瓶颈依据的机制探索，不支持宣称迁移已显著成功。

本轮仍复用原24个开发布局、原2误差与bounded舍入，不把这些重复局当新独立证据。配置见configs/round02.json：

- ADAPT_ENTRY / ADAPT_GATED、PAIR_ENTRY / PAIR_GATED：只改变光学覆盖点访问顺序，从最近网格点进入后选择完整移动较短的双分支排列；点集不变。
- ADAPT_SHADOW / ADAPT_GATED：只删除可由正负测点推导必在背面的共享尝试；不裁剪源位置集合。
- ADAPT_ENTRY_SHADOW：前两个独立因素的组合。
- ADAPT_VALUE_GATE / ADAPT_GATED：把条件方位收缩门控也用于自适应定位测点选择；可能导致过早光学兜底，作为合理负方向保留。
- CENTER_BLIND / CENTER：无线电已到达中心却无信号时，增加一次原地3秒光学尝试；只有中心在P内才尝试，不增加该次移动。定向近场可无信号但可光学清除，故该机制有明确物理动机。

先按完整清除与整局均值选开发父方案，保留P95/最差退化。下一批独立验证使用seed171000的48个新布局、四误差×两舍入。若这些新因素的稳定边际收益均小于约1%或为负，将停止扩展机制，锁定最终候选与代表性消融，使用seed191000的120个新布局完成最终报告。现有验证不用于最后独立成绩；若改选会明确记录。
