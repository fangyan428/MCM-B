# R6 可行集合与必访搜索站的滚动联合行程

前五项定位机制尚未超过冻结基线，最好组合SHARED_PARALLAX均值仍慢0.99%、P95恶化。旧任务入口评分针对旧大交角测点，与新定位流程可能不相容。

R6核心机制：把所有未清目标的当前集合中心与必访七站放入同一开路行程，对每种起点构造最近邻路径并作严格下降的2-opt，执行首任务后根据真实公开反馈重新规划。没有读取真实目标终点。NEAREST_*为删除全行程规划、只比较集合中心入口的机制消融；TOUR_*为完整机制。分别配在HOMING及SHARED_PARALLAX上识别交互。相同几何和观测机制不变。

静态代理路径优化不等于整局最优。中心代表一个有界集合，并非真实位置，也不使用均匀源分布假设。无数值搜索。全部已知源任务最多16，搜索任务最多7，滚动规划不创建无穷调度任务。
