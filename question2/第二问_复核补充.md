# 第二问复核补充：为第三问提供可靠基线

本次完整读取题面、附件1/2及第一、二问已有文稿、代码。第一问求解器不改写；第二问保留半平面模型、保证接收条件和实验数据，仅为 `candidate` 增加 `error_deg` 参数，使接收几何与交集误差使用同一角度包络。原默认值仍为1°，原有8项测试通过。

## 1. 结论的证据等级

| 内容 | 复核结论 | 证据等级 |
|---|---|---|
| 源距离5<r≤1500；同一源R≥max(1000,r) | 正确，必须保留首次接收成功信息 | 题面事实＋推论 |
| 对所有候选G要求||Q−G||≤max(1000,||G−S||) | 固定未知R下的保证接收充要条件 | 已证明 |
| 完整扇形的四圆盘交集／h不等式 | 原推导正确；不能直接把所有源的R设为1000或1500 | 已证明 |
| cmin/M≥sinγ | 是排除病态几何的充分条件，并非最大可行区域 | 已证明的保守条件 |
| γ=20° | 便于稳健设计的参数，不是题面常数 | 自行选择 |
| (800,±605)与134.284米 | 来自固定范围、固定候选域和有限网格；不是全局最优或连续最坏上界 | 离散实验 |
| “优先最大化90°交会” | 只在距离固定的比较中成立；一次角度不知道源距离 | 有条件结论 |
| 最坏多边形直径最小 | 合理的定位质量目标，但不等价于清除最快 | 自行选择的目标 |

原文的`候选区域`是分层的：实际源可行域对应的接收区域 → 全扇形外包的接收区域 → 加入交会角充分条件的安全区域。后两次收缩可能保守，不能混称为全部可选位置。

## 2. 固定移动步长的地位

第二问并没有要求固定步长。原算法实际上是同时搜索(a,b)，得到一个局部坐标偏移；其长度1003.008米只是所选算例参数的结果。

第三问可以用这个偏移建立可解释基线，因为其可接收性可以解析验证；不能把它称为“所有源的最佳第二步”。例如源实际上离首测点很近时，移动一公里通常浪费时间。更关键的是，搜索阶段结束后机器人当前位置X可能已经远离保存首测读数的S；第三问的真实移动距离是||Q−X||，不是||Q−S||。本轮基线按真实动作位置计时，没有漏掉这段移动。

本轮不进行新的步长调参，也不把调整步长包装成已验证创新。后续候选可以根据已知源区域、当前位置及可清除性自适应选择Q，审批后再实验。

## 3. 误差与舍入

题面给±1°，附件2另给两位小数，未明确误差界是否包含最终舍入。无需先猜一个解释才能继续：第三问策略统一用1.005°包络，兼容“输出总误差≤1°”和“先产生±1°误差再四舍五入”两种解释。

这属于保守实现选择，不改变题面标准。自建主环境输出保证总误差≤1°且读数有两位小数；另外明确标记`pre_round_stress`的舍入压力环境，只用于验证这个不确定实现细节，不冒称官方规则。

扩大误差时，必须同时扩大交集角度和候选区域计算的角度。已将`candidate(q, min_angle_deg=20, error_deg=...)`改为使用传入值；第三问调用1.005°。固定点(800,605)在该值下仍满足保证接收条件，近端接收距离平方约束尚余1842.65平方米余量，解析锐化交会角下界约36.26°，高于选定的20°。

## 4. 优化目标的改进方向

第二问建议继续保留直径作为简单、分布无关的效果指标，但正文明确“不包含移动时间”；若强调实际清除，可将目标替换为覆盖圆半径或预期剩余动作代价。

第三问必须以字典序目标组织：首先保持全源发现及清除证据完整，再在有效策略中减少总虚拟时间。不能拿少扫描频道、提前退出换取漂亮的平均时间。

后续可在约束“保证接收＋不退化”的前提下比较移动预算B下的定位直径曲线，或根据实际可行区域评价清除点数量。当前未实现这些候选，也没有对应对照、消融或新案例结果。

## 5. 复用边界

第一问的多边形直径和顶点算法继续复用；第二问解析候选条件继续复用。第三问没有把直径/2当作可靠覆盖半径，而是用间距不超过28米的方格中心覆盖定位包围盒，每格最远距离小于20米。这个简单后备办法牺牲效率，但便于证明有限步清除。
