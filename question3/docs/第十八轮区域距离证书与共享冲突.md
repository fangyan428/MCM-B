## 连续几何保证及其前提

首次点S在1800米圆内，真实源为G=S+ru，首次方向角偏差满足|α|≤δ。由|G|≤1800，对固定单位方向u有

`r ≤ −S·u + sqrt((S·u)² + 1800² − |S|²)`。

右侧关于投影S·u单调不增。令m为测得方位±δ区间内S·u的最小值：在两个角端点及区间内可能出现的反S方向中取最小，即得

`U_exact = min(1500, −m + sqrt(m²+1800²−|S|²))`。

算法采用向外放大的U。区域来源是题面公开边界；不是估计实际源距离，也不是知道实际接收半径。首次点在区域外时此推导分支不使用。

在测得方位为局部x轴的坐标系中，令第二点偏移q=(a,b)，a≥0，n=a²+b²，

`h=a cosδ−|b|sinδ`，`c=|b|cosδ−a sinδ`，`F(r)=n+r²−2rh`。

对所有|α|≤δ，有|G−q|²≤F(r)。F关于r凸，所以[5,U]的最远距离由两个端点上界控制，记 `M²=max(F(5),F(U))`。

- U≤1000：要求F(5)和F(U)均小于1000²。
- U>1000：要求F(5)≤1000²，且n≤2000h。第二条件在r=1000保证接收，并因h≥0使n−2rh在r≥1000不增；于是对全部r≤U满足|G−q|≤max(1000,r)。实际R≥max(1000,r)，故保证收到信号。
- 要求c>5且c≥M sin(20°)。由垂直分量下界可知第二点距离大于5米且两条真实方位线交角至少20°；配置还要求最小交角>4δ，以保留原两误差扇区交集有界的条件。

实现用1e−4平方米接收余量及1e−7米交角/近距余量，U加1e−5米外扩再向上取整。以上实数命题已推导；浮点实现采用保守余量并经过测试，不冒称形式化区间算术证明。原误差1.005度和同点固定误差规则保持。

`tests/test_domain_range.py` 覆盖区域边界、角度跨±180/360度、区间跨1000米、原完整区间不合法而短区间合法的偏移、当前点、原分支完全回退、晚源/边界场景、伪造第二点no_signal后返回incomplete。独立审计从接受方位重新计算极值角、几何不等式和真实源包含关系，不调用策略的range_upper/certified函数。`round18_tamper_audit.py` 另将日志证书改成U=6或偏移(0,0)，两次均实际被拒绝。

## 下一项最值得验证：共享目标也使用同一合法距离证书

当前主目标按其区域截断扇区选点，但其它已知频道的S资格仍要求对完整5～1500米扇区成立，过度保守地拒绝了同一点的合法共享机会。下一轮应按每个待共享频道自己的首次位置、方位和区域上界认证同一个实际第二点，保留原完整扇区判断作回退。只用已知反馈，不读取真实距离/隐藏类别，不为未知频道编造测量。

公开日志的只读资格诊断已完成，见 `diagnostics/round18_shared_opportunities.py` / `results/round18_shared_opportunities.json`。在聚集16源例的第一个新第二点(1465.9728,−174.5784)，其余15个已知频道都通过收紧证书，却不通过原完整扇区证书。开发主/舍入有57/56个定位决策出现此类额外资格；新外缘418/420个。1464/1503个外缘资格计数包含同一频道在多次决策的重复机会，不能当成独立源或真实节省的检测次数。

这提供了明确的组合冲突和修复方向，但当前**尚未实际执行扩展共享策略，没有它的收益数字**。下一轮应对照FREE、仅主目标收紧、仅共享收紧、两者组合，保持相同固定案例与预算，检验是否互补而非假设组合最好；再依预设门槛另锁新布局。普通布局可能因过多共享而变慢，新增资格仍不等于划算；若修复无法通过均值/P95及完整清除门槛就放弃。当前新验证案例已看过，不再充当未来独立验证。
