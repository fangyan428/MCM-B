# 第三问后续优化：证据、三条候选与小规模开发探针

> 本文件为候选提出阶段的历史报告；后续三个方向均已实现并完成开发单项/组合实验，见[第三轮单项与组合实验审查](第三轮单项与组合实验审查.md)。

当前保持AB为官方演练候选。本次只完成公开日志诊断、一个可选几何分支及固定开发对照，现提交人工审查。未启动官方模拟器，未做正式测试，未展开第四问。更复杂不等于更优，下面的机制均不宣称学术首创。

## 1. 优先级依据

AB在此前新布局主批中平均总时间5433.79秒，其中移动4768.01秒，占87.75%。光学阶段虽有1742.95秒，但进一步按公开动作轨迹拆分为：接近第一个清除点移动1615.95秒、同一源后续网格内部移动37.29秒，以及光学/激光动作89.71秒。前一项大部分是在接近源，不能都当成可消除的网格浪费。

本次对既有200条AB轨迹进行事后诊断，不读取隐藏坐标：

- 2548次两点定位中，964个候选多边形可由一个半径严格小于20米的圆覆盖；其中590次现有包围盒方法生成了多个网格点。
- 2548个已实际使用的第二检测点中，772个（30.30%）也满足至少一个其他已发现、未清除频道的第二点解析接收及20°交会条件，共1055个兼容关系。检查只用当时已获得的首测位置、示向度及当前检测点，没有预读其他源未来观测。

772次是公开轨迹上的几何机会数，不是可节省772次检测，更不是预计节省30.30%的总时间。同一源可能在多个时刻重复计数，策略改变后轨迹也会改变。既有10000—10049布局现已用于设计诊断，不再作为下一轮未见验收集。

诊断脚本：`diagnostics/opportunities.py`与`diagnostics/shared_points.py`；对应结果：`results/optimization_opportunities.json`、`shared_point_opportunities.json`。

## 2. 三条机制不同的候选

### 候选一：多个源共用第二检测位置（优先推荐，尚未实现）

**基线缺陷**：AB把每个源的第二次测向当作独立目的地，忽略一个位置同时适合多个频道的可能。

**修改机制**：已发现源c的首测为(S_c,θ_c)，把全局候选点Q转到其局部坐标后复用第二问的解析充分条件。只有Q同时通过多个源的接收、非near及交会证书，才考虑在该点依次测向这些频道，并分别保存两次测向的候选多边形。每次检测和切频仍按题面收费；测量信息不能跨频道混用。之后分别完成各源清除。缺少兼容点就回退原AB的独立第二点。

**预计收益与代价**：有机会减少到独立第二点的专门移动，不以省检测费为卖点。代价是测向与清除不再始终紧邻，需保存待清除区域并安排其顺序；共同检测点也可能导致后续清除绕路。因此不能只累计“少走到第二点的距离”就宣称总时间获益。

**对照**：先只在AB原本选中的第二点补测一个满足证书的其他频道，控制模块规模；比较AB、共址复用、共址复用但按固定频道清除的消融。若进一步联合选择共享位置，应作为后续独立版本。所有方案用同一批场景和同点固定误差场，比较完整清除、停止证书、总时间及尾部。

**放弃条件**：任何证书失效、漏源或假完成即停用；若省下的第二点移动被后续清除绕路抵消，或新集达不到原拟议中位改善5%/最差回退不超过10%的目标，不并入主方案。阈值仍是项目审查约定，不是赛题规定。

### 候选二：同一任务集合的顺序比较（第二优先，尚未实现）

**基线缺陷**：上一轮H把完成一个源的成本与扫描一个站的短任务直接比较，倾向先把搜索做完；AB仅看任务起点距离也可能局部贪心。

**修改机制**：让两个备选方案都完成同一个“一个搜索站＋一个已发现源”的小任务集合，比较先扫站后清源和先清源后扫站的增量移动；共有且必做的动作成本应在两边以相同口径计入。候选终点区域只影响排序，不影响真实可行域和停止证书。保持原AB回退及搜索进度约束。

**预计收益与代价**：可能减少局部折返，同时修正上轮比较范围不一致的问题。代价是终点仍未知、扫描可能发现新源，预测与实际路径仍会偏离；不能保证改善。

**对照**：AB、同任务集合顺序比较、上一轮H05作为负面对照；限制为一站一源，暂不扩大规划深度或堆叠权重。

**放弃条件**：继承上述安全和收益门槛；如果仍将大量定位推迟到搜索结束或尾部恶化，则放弃，不继续靠加大搜索深度掩盖问题。

### 候选三：有几何证书时一次清除（D，已做开发探针）

**基线缺陷**：首测方向包围盒网格可能过于保守，即便整个多边形已能被一个20米圆覆盖，也生成多个点。

**修改机制**：对两测向交集P的顶点枚举单点、两点中点、三点外心提出圆心，选最大顶点距离最小的候选。仅当所有顶点距离≤20−10⁻⁵米且原网格多于一个点时，用该圆心做一次清除；否则完全回退原网格。圆为凸集，包含所有顶点便包含整个凸多边形。这与“直径≤40就一定能一次清除”不同，后者被等边三角形反例否定。候选枚举的浮点误差可能造成保守回退，真正安全检查始终是逐顶点覆盖，仍非任意精度形式化认证。

**收益与代价**：减少部分光学失败和格间移动，计算成本小；但清除终点改变后仍可能影响下一段路径，不能证明总时间单调改善。当前证据表明收益很小，宜定位为几何完善，不作主要创新点。

**对照与放弃**：原AB与AB+D，每份配置仅一个固定参数版本；主开发52例、舍入压力同52例，未新增调参。收益若不足以抵消维护成本，可保持关闭；未参加调参的新案例验收尚未执行。D可在C之前作充分证书分支，未满足证书则继续C，但本轮未测试D+C组合，不宣称其收益。

## 4. 推荐与审查边界

推荐保持当前AB开展官方演练准备；研发优先候选一“共用第二检测位置”，候选二作备选，D暂不默认启用。本轮证据不支持把D的约0.17%收益包装为重大创新，也不支持把30.30%的共享点机会率等同于收益率。

候选一、二是待实现机制，不含未经运行的成绩；候选三只有开发证据。后续若批准继续研发，应先完成一条主方向及针对性消融，锁定参数后使用全新预留布局验收；不重复使用10000—10049作为未见集。当前在“新候选与开发探针完成”节点暂停，等待用户选择研发方向。正式测试仍须另行明确授权。
