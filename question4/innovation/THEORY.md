# 定向迁移的几何依据与验证边界

## 状态与信息约束

策略只使用公开的10–16源上界、20个频道、源域半径1800米、接收半径1000–1500米、方位误差及四API响应。每个已知频道维护由正向方位半平面交得到的保守凸多边形 P；第一条方位还与1500米扇形外包及源域外包相交。沿用1.005°误差包络，包含最终误差±1°以及先误差后保留两位小数的压力模型。

定向源在真实接收圆盘与发射闭半平面的交集中才可返回方向或near。`distance <= 5` 仍可因处于背面而无信号。光学清除的20米条件与发射方向无关。

因此本轮不使用Q3的“所有候选距离<1000米，所以必收到信号”推理。<1000米仅作为共享成本筛选。任何尝试收到 `no_signal` 时保留 P 原样，不能像全向源那样减去阴性圆，也不能把它当作接收契约故障。

## 自适应测点与完整清除

从 P 的最长顶点对中点构造中心 c，并用全体顶点到 c 的最大距离 R 作包含圆证书。中心型直接向 c 测向；尺度视差型候选为 c ± sqrt(20R) v，v为初始方位的法向，先走距离当前位置较近的一侧。正向响应收缩 P 后重新计算；无信号可尝试另一候选。达到8步、所有候选无信号或收缩不足10%时退出无线电尝试。

R < 20米（另留数值余量）时，凸性保证 P 的所有点都在清除圆内。否则沿用有限光学覆盖：在初始方位坐标系取 P 的外包矩形，边长切成至多28米的小格，格中心距格内任一点不超过14√2 < 20米。有限网格至少有一个点可以清除真源，与方向和无线电阴性无关。无线电尝试的有限上界与光学有限覆盖共同保证已知频道终止；实际协议故障/截止仍应明确标记incomplete。

未知频道保留原25站连续三角覆盖，每个相关三角形边长严格小于1000米，域内源在三角形中，任意穿过源的发射半平面至少包含一个顶点。因此若源尚未被清除，完整扫描站点会发现它；只有成功清除16源，或完成覆盖且无已知待处理频道，才退出。

## 途中共享与条件门控

定位/光学清除实际移动后，对其他已知未清除频道可在当前位置额外检测。共享本身不增加移动，但可能增加切频、检测并改变后续路线，故只有整局时间比较才能确认净收益。每个频道记录所有已尝试坐标，包括无信号，避免固定空间误差下重复原地尝试。已获20米清除证书的频道无需再检测。

门控先覆盖从 P 在测点张成的所有可能**正向读数**，划分为16个角度区间，每个区间再扩大半个区间宽度与1.005°误差。对扩大后的方位交集验证包含半径不超过原半径的一半或20米目标，所有区间都通过才尝试共享。扩大区间避免仅抽样16个输出所产生的空隙。

这只能证明“如果收到正向读数，则会得到足够收缩”。它不包含 `no_signal` 分支，不是全结果信息价值证书，不是接收概率，也不保证净省时间。无信号保持 P 不变，因而不损害完整性。

另外有一个适用于定向源的严格接收充分条件：历史正向测点的凸包属于真实接收集合，因为圆盘与半平面交集是凸的。首个正测点时该凸包退化为一点，通常不能支持移动。该命题与一般的距离筛选应在论文中分开，不能混称。

## 证据层次

几何推导说明理想实数模型下的保守性；实现使用浮点余量，不能称为形式化区间算术证明。自建测试验证方向边界、近场背面、极端误差、集合包含、阴性不收缩及有限兜底。运行后独立审计逐动作物理、整局计时、停止证书，并检查中间集合包含真源。只有评估器在运行结束后读取真源，策略无真值接口。

时间均值、P95、最坏案例与bootstrap区间仅描述指定自建生成器，不代表逐案例优势、官方性能或全局最优。源码锁、配置锁、布局生成时间及开发/验证分离均单独存档。

## R2追加机制

光学最近入口保留原网格所有点，仅取最近点k，比较“从k到首端再到末端”和“从k到末端再到首端”两个完整排列。覆盖与有限终止不变；提前命中是性能启发式，完整移动较短不等于部分执行必定更快。

定向阴性影区证书：若历史阴性点n到当前P全部顶点均<1000米，则n对真源必在背面。历史正测点a_i位于正面。q=n+Σλ_i(n−a_i)、λ_i≥0时，任意实际发射半平面的线性函数满足h(q)=(1+Σλ_i)h(n)−Σλ_i h(a_i)<0。因此只跳过已经能证明无信号的额外共享，不删除任何未知频道扫描，不裁剪P。实现只接受两个正点构成的非退化二维锥严格内点，边界和病态情况不出证书。运行后独立审计再用真值核对被跳过点。

中心无信号后的原地光学尝试仅耗3秒光学成本；成功是公开clear响应确认，失败则继续原有限兜底。它不把无信号视作近场证据。定位提案信息门控同样只覆盖正向读数分支，可能使本来有用的尝试被删去，必须保留负结果。
