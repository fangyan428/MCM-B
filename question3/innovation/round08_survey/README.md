# R8 先多站观测网络、后集中清除

核心机制：分离全域多站观测与目标清除，把七个覆盖站同时作为一个对所有未清频道的观测网络。已知频道继续在新站检测，有信号则与所有旧方位相交，无信号保留为真实反馈但不据此误判不存在；near立即清除。七站完成后才根据多方位可行集合规划清除开路，并对尚不足以直接清除的源调用自适应集合逼近。

与旧逐源二点流程、R4沿目标定位路径共享不同，它用全局观测的集中阶段构造定位信息；可能大幅减少定位绕行，也可能因七站重复测向和远区只被一站接收而付出过高代价。每站每未清频道至多一次。16源已被发现时跳过未知频道，但继续对已知源取信息；停止仍要求全部清除。

无数值搜索；BASE/SURVEY完整流程对照。仍使用七站足覆盖的数学证书，不把有限站无信号错误推广到定向题。
