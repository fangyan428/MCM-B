# R10 用真实阴性检测圆完成连续覆盖证书

核心机制：退出证书从“每个未知频道必须扫完固定七站”推广到“该频道全部实际no_signal点的1000米圆覆盖公开目标域”。在一个清除/定位后的实际当前位置，若加上此点即可补齐某频道的覆盖，则原地检测它；no_signal即可闭合该频道证书，direction/near则按真实反馈继续定位。没有凭空添加阴性观测，也不提前认定10源完成。

等半径圆覆盖由目标圆盘上到最近阴性点距离的最大值判断。候选极值包括圆内三点等距中心、两点垂直平分线与目标边界交点、各站在目标圆上的最远点；这是Voronoi分区上二次距离函数的极值枚举。浮点安全余量1e-4米。新完整停止由独立自适应方格细分审计：每个与目标圆盘相交的方格必须整体落入一个实际阴性圆；不复用策略的Voronoi枚举公式。

原七站仍为搜索回退。只在当前位置能立即补齐覆盖时探测未知频道，不增加无目的巡游。COVER_TOUR_SHARED_PARALLAX对照TOUR_SHARED_PARALLAX，检验几何停止创新的完整成本。
