# 图1与图8：第一批视觉重绘

本批只重绘正文图1（整体路线）与图8（Q3调度流程）。几何小图属于非定量概念示意；没有新增实验、筛选观测或改动算法。沿用Python/matplotlib，输出可编辑PDF、SVG及300 dpi PNG。

## 图形契约

|图|要回答的问题|构图与证据角色|
|---|---|---|
|图1|四问的方法如何逐步衔接？|四个等宽单元依次表示几何基础、鲁棒选点、全向搜索和定向扩展；下方闭环只描述Q3–Q4的在线执行。小图不承担几何证明。|
|图8|搜索与源服务如何被统一调度，何时结束？|任务池输入、开放路径排序、互斥执行分支、任务完成后的记录更新与停止核验；显式保留两种停止条件。|

继承原有字体及青蓝、橙色体系，重新设计布局；参考材料只提供模块分组与视觉层次的思路。图1各单元的几何对象为概念示意，未以新的坐标、角度或轨迹宣称实验事实。图8的共享观测为源服务内部的有条件操作，不能解释为每站无条件补测，也不能解释为每次测向后立即重排主任务。

## 复现

在项目根目录，使用已安装matplotlib、numpy、fonttools及pymupdf的Python；还需本机的nature-figure对齐审计脚本、Alibaba PuHuiTi常规字体和Noto Sans CJK粗体字体集：

```bash
python manuscript/story_draft/analysis/redesign_flow_figures.py --comparisons
```

本脚本独立绘制两图。重建历史整套图时，应在原有两轮绘图脚本之后执行本脚本。`before/`保存本批修改前的两张矢量原图，用于改前／改后对照。

图1的四个单元按最终渲染绘图区执行1.5 pt对齐检查；图8是单一流程绘图区，对齐检查不适用。两张正式PDF另做字体和碰撞审计，再检查论文实页。自动报告及人工核查结论保存在本目录。

为兼容PDF嵌入，绘图脚本将所需Noto粗体字形在临时缓存中转换为TrueType轮廓；PDF和SVG仍保留文字。最终核查使用PDF实际渲染，不能只看matplotlib直接输出的PNG。
