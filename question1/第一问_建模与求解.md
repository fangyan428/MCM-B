# 第一问：基于半平面交的定位区域直径计算与圆覆盖判定

## 1. 问题目标与建模范围

输入同一干扰源的 n 个检测点坐标 Sᵢ=(xᵢ,yᵢ) 和示向度 θᵢ，依据题面附录 2 的 ±1° 误差界，构造交会定位多边形，计算区域内任意两点距离的最大值，并回答是否存在一个直径等于该最大值的圆覆盖整个区域。

本问没有给定具体数值数据，故交付通用算法及自行构造的可复现实例。所有示例均为验证案例，不是正式测试数据；本问不需要调用模拟器。

这里的定位区域取题面附录 2 图 2 所定义的**测向角约束交集**。不额外截断检测射线，不将示向度中心射线的交点作为精确位置。若进一步加入半径 1800 米的目标圆域或有效接收距离约束，交集可能含圆弧，不再是本问的纯多边形；本文算法不能直接把圆弧端点当作全部极值候选点。可以用本文多边形作为保守外包区域，但其直径不一定等于加入这些约束后的真实可行域直径。

题面只给误差范围，没有给出独立性或概率分布，因此采用确定性有界误差模型，不假设高斯误差，也不利用同地点重复测量缩小误差界。

## 2. 从测向扇区到线性不等式

设 δ=1°，定义扇区的两条边界方向：

\[
u_i^-=(\cos(\theta_i-\delta),\sin(\theta_i-\delta)),\qquad
u_i^+=(\cos(\theta_i+\delta),\sin(\theta_i+\delta)).
\]

记二维叉积为 [a,b]=aₓbᵧ−aᵧbₓ。候选点 p=(x,y) 位于第 i 个闭扇区的充要条件为

\[
[u_i^-,p-S_i]\ge0,\qquad [u_i^+,p-S_i]\le0.
\]

因为扇区张角为 2°<180°，以上两式同时限定了方向和角度，不会错误包含检测点背后的反向扇区。以三角函数表示还可以直接处理跨越 0°/360° 的读数。

写成标准半平面形式：

\[
a_{2i-1}=(\sin(\theta_i-\delta),-\cos(\theta_i-\delta)),
\quad b_{2i-1}=a_{2i-1}\cdot S_i,
\]
\[
a_{2i}=(-\sin(\theta_i+\delta),\cos(\theta_i+\delta)),
\quad b_{2i}=a_{2i}\cdot S_i.
\]

于是定位区域为

\[
\boxed{P=\{p\in\mathbb R^2:Ap\le b\},\qquad A\in\mathbb R^{2n\times2}.}
\]

半平面是凸集，故 P 是凸集。非空、有界且有内部的情况下，P 是凸多边形；退化时可能是线段或单点，也可能出现无界交集。空集表示读数或建模假设不相容，不能解释为“直径为零、已精确定位”。

## 3. 直径算法

### 3.1 可行性与有界性

先用线性规划求一个满足 Ap≤b 的点。不可行则返回 `empty`，直径未定义。

若可行，分别最小化 x、−x、y、−y。任一目标无界则 P 无界，直径为 +∞，返回 `unbounded`。四个方向均有有限最优值，则 P 被有限矩形包围，因而有界。

程序为保证 JSON 兼容，空集和无界情形的 `diameter` 都输出 `null`，必须结合 `status` 区分；无界状态的数学直径是 +∞。

### 3.2 枚举有效顶点

记 m=2n。对每对不平行的边界直线

\[
a_j\cdot p=b_j,\qquad a_k\cdot p=b_k
\]

解二元线性方程得交点 q。若 q 满足全部 m 个不等式，则保留为候选顶点，随后去除重复点。有限多边形的每个顶点都是至少两条不平行有效边界的交点，因此不会遗漏顶点。线段的两端和单点也可由此获得。

设去重后的顶点为 V={v₁,…,vₖ}，计算

\[
\boxed{D(P)=\max_{1\le i,j\le k}\|v_i-v_j\|_2.}
\]

同时保存达到最大值的一对顶点 A、B。若只有一个顶点，D=0。

### 3.3 为什么只需检查顶点

任意 p,q∈P 都可以写成顶点的凸组合：

\[
p=\sum_i\alpha_i v_i,\quad q=\sum_j\beta_jv_j,
\quad \alpha_i,\beta_j\ge0,\quad\sum_i\alpha_i=\sum_j\beta_j=1.
\]

因此

\[
\|p-q\|=\left\|\sum_{i,j}\alpha_i\beta_j(v_i-v_j)\right\|
\le\sum_{i,j}\alpha_i\beta_j\|v_i-v_j\|
\le\max_{i,j}\|v_i-v_j\|.
\]

反过来顶点属于 P，故等号在某对顶点上取得。这证明算法计算的是整个区域的直径，而非仅一个近似。

### 3.4 伪代码与复杂度

```text
输入：检测点及示向度，误差半角 δ=1°
构建 m=2n 个半平面 Ap≤b
若不可行：返回 empty
若任一坐标方向无界：返回 unbounded
V ← 空集
对每一对不平行边界：
    计算交点 q
    若 q 满足所有半平面：将 q 去重后加入 V
枚举 V 中所有点对，求最大欧氏距离 D 及端点 A,B
c ← (A+B)/2
covers ← 对所有 v∈V，均有 ||v−c||≤D/2
返回 V,D,A,B,c,covers
```

除固定次数的二维线性规划外，枚举 O(n²) 个边界交点、每个检查 O(n) 个约束，复杂度为 O(n³)。有效顶点数 k≤2n，枚举顶点距离为 O(k²)。保存约束、顶点和距离矩阵的空间复杂度为 O(n+k²)；将距离矩阵改为逐对更新最大值可降为 O(n+k)。当前实现优先采用易复核的枚举方法。

如检测点数量很大，可用按方向排序的半平面交算法求凸多边形，再用旋转卡壳求直径，几何计算部分可降为 O(n log n+k)。本文代码未实现该优化，不将其计入实测性能。

## 4. 以 D 为直径的圆能否覆盖 P？

### 4.1 一般不能，且圆心没有自由选择空间

设 A、B 是直径端点，即 ||A−B||=D。任何半径为 D/2 且同时包含 A、B 的闭圆盘，其圆心 c 都必须满足

\[
D=\|A-B\|\le\|A-c\|+\|c-B\|\le D.
\]

两处不等式必须取等号，因此 c 必须位于线段 AB 上，且到两端距离均为 D/2，即

\[
\boxed{c=(A+B)/2.}
\]

所以任取一对直径端点，只需检查

\[
\boxed{\max_{v\in V}\|v-(A+B)/2\|\le D/2.}
\]

该条件是“存在直径 D 的覆盖圆”的充要条件：必要性来自圆心唯一性；充分性来自圆盘的凸性——包含全部顶点就包含其凸包 P。如果检查不通过，换一个圆心也不能解决问题。

### 4.2 与题目测向条件相容的反例

取等边三角形顶点

\[
V_1=(0,0),\quad V_2=(20,0),\quad V_3=(10,10\sqrt3).
\]

其直径 D=20 米。以下三组检测数据的 ±1° 扇区交集恰好为该三角形：

| 检测点 | x（米） | y（米） | 示向度 |
|---|---:|---:|---:|
| S₁ | −1000 | 0 | 1° |
| S₂ | 520 | −500√3 ≈ −866.025404 | 121° |
| S₃ | 510 | 510√3 ≈ 883.345912 | 241° |

构造方式：沿三角形各边逆时针方向取单位向量 eᵢ，令 Sᵢ=Vᵢ−1000eᵢ，并将示向度设为该边方向角加 1°。每个扇区的下边界即三角形的一条边所在直线，对应左半平面。三个下边界半平面的交就是该三角形。

对于每个检测点，相邻顶点位于下边界，第三个顶点相对于边方向的偏角为

\[
\arctan\frac{10\sqrt3}{1010}\approx0.98247^\circ<2^\circ.
\]

故整个三角形也满足三个上边界约束，上边界不再切去任何部分。因而六个半平面的交集严格等于该三角形，不只是一个抽象几何反例。

取三角形中心 G=(10,10√3/3) 作为真实干扰源，其相对三个检测点的真方位分别约为 0.32752°、120.32752°、240.32752°，与读数误差绝对值均约为 0.67248°，满足 ±1°；三个检测距离均约 1010.0165 米，可取有效接收半径为 1200 米的全向源，且所有点在目标圆域内。因此反例也符合题目物理条件。

以 V₁V₂ 为直径的圆，圆心 (10,0)，半径 10 米；第三个顶点与圆心距离为 10√3≈17.320508 米，在圆外。由上一节的唯一性证明，不存在其他直径为 20 米的圆覆盖这个三角形。

其最小覆盖圆是外接圆：

\[
R_{\min}=\frac{20}{\sqrt3}\approx11.547005\text{ 米},\quad
2R_{\min}\approx23.094011\text{ 米}>D.
\]

### 4.3 可安全使用的覆盖半径界

对任意平面非空紧集，其最小覆盖圆半径满足

\[
\boxed{D/2\le R_{\min}\le D/\sqrt3.}
\]

下界由直径两端必须被覆盖直接得到。上界可由最小覆盖圆的支撑点结构证明：最小圆或由两个对径点确定，此时 R=D/2；或由三个边界点确定，圆心位于这三点的三角形内。这时三个相邻圆心角均不超过 180°，且至少一个不小于 120°，对应弦长至少为 √3R，故 D≥√3R。等边三角形达到上界。

这里的上界只保证**存在合适圆心**；不能把任意估计位置当作圆心。后续若要保证光学清除，应直接计算或验证某一行动点 c 的最大可能距离 maxₚ∈P||p−c||≤20 米，而不能仅凭 D≤40 米断言清除必然成功。本段只是第一问结论的含义，不涉及后续搜索策略实现。

## 5. 实现、复现和数值注意事项

文件：

- `solve.py`：半平面构造、区域状态判定、顶点枚举、直径和覆盖判定。
- `test_solve.py`：边界情形及随机案例验证。
- `example_result.json`：等边三角形反例的实际运行输出。

在项目根目录运行：

```bash
python question1/solve.py
python -m unittest discover -s question1 -v
```

也可输入 JSON 文件：

```bash
python question1/solve.py measurements.json
```

输入格式为数组，每个元素含 `x`、`y`、`bearing_deg`，例如 `{"x": -1000, "y": 0, "bearing_deg": 1}`。依赖 Python、NumPy、SciPy；距离单位为米，输入角度为度，内部转为弧度。

代码将半平面法向量归一化，顶点可行性和去重的默认距离容差为 10⁻⁷ 米，平行判断阈值为 10⁻¹²。浮点计算不是任意精度几何：近乎平行的边界、极大坐标或小于容差的狭窄区域可能需要高精度计算及容差复核；不能把当前测试视作覆盖全部病态输入。程序在无法恢复有界区域顶点时明确报错，不伪造结果。

附录 2 的数学误差模型使用 δ=1°。附件 2 另说明接口读数保留两位小数；若后续确认是对有误差角度再进行最近舍入、且 ±1° 不包含舍入误差，可调用 `solve(measurements, error_deg=1.005)` 保守包络。第一问推导与默认实现严格使用题面 1°，不擅自改变参数。

## 6. 验证结果与对抗式检查

实际执行 11 项测试，全部通过；其中随机案例测试内部包含固定种子的 50 组独立构造案例。

| 检查对象 | 验证内容 |
|---|---|
| 3×4 矩形 | 直径为 5，直径圆覆盖成立 |
| 三组真实扇区构成的等边三角形 | 恢复三个预期顶点，直径为 20，直径圆覆盖失败 |
| 不相容半平面 | 返回 empty，不报告零直径 |
| 单次测向扇区 | 返回 unbounded，不用任意框裁剪伪造有限直径 |
| 线段、单点 | 分别得到长度、零直径 |
| 359.8° 读数 | 正确跨过 0°，排除反向点 |
| 重复平行约束 | 仍恢复正确矩形直径 |
| 全负坐标区域 | 验证线性规划没有误加非负变量限制 |
| 随机真源与有界误差 | 真源满足半平面约束，顶点可行；投影宽度不超过计算直径 |
| 非法输入 | 拒绝空测量列表和非有限数值 |

对抗式复核重点：① 不把角度误差当位置误差；② 不将半射线扩展成双向直线扇区；③ 不把空交集视为精准定位；④ 不能用任意大矩形处理无界性；⑤ 圆覆盖反例不仅证明某个圆心失败，还证明所有圆心都不可能；⑥ 三角形确实能由本题的 2° 扇区产生；⑦ 圆域裁剪后的曲边区域不混同于纯多边形。

最终结论：用 2n 个半平面构建交会定位凸多边形，枚举有效顶点并计算最远顶点对即可精确求出其直径；以该直径为直径的圆**不一定**覆盖整个区域，覆盖与否由直径端点中点到所有顶点的距离检验确定。
