# R2 随不确定尺度改变的视差基线

R1完整开发主批均值4295.98秒，对冻结基线3855.12秒慢11.44%，P95也恶化。中心直进在径向不确定时会反复折返，不能把局部路程直线化当总时间收益。

R2独立核心机制：第一次精化不再走集合中心，而走中心两侧的视差点；横向长度由 sqrt(集合覆盖半径×20米)给出，20米来自光学清除范围。每点核对全部可行顶点的1000米接收证书，选离当前点较近的一侧；之后再用中心收缩。无数值搜索，平方根尺度是启发式，不是最优性定理。HOMING是去掉视差点的消融。

本轮同时对照 BASE/HOMING/PARALLAX；上一轮数据保留。若失败照样保留并放弃，不调整尺度追结果。
