## 已检查的性质

`build_fixtures.py` 是 evaluator-only 生成及合法性检查脚本；没有导入或运行任何候选策略。可复现命令：

```bash
python -m paper_evidence.q4_mechanism_reset_20260912.stress.build_fixtures
```

`fixture_validation.json` 保留逐布局源数、定向数、最大位置半径、几何摘要及公开响应见证。边界、近场背面和接收半径见证通过真实自建 Client/Simulator 的 measure 响应核对，原地重复测量必须返回完全相同的读数。另对每布局全部源交叉四种误差和两种舍入，检查同点误差固定，以及 bounded ≤1°、pre_round_stress ≤1.005°。这是评估器物理一致性验证，不是候选性能运行。

全部几何点显式保证 `hypot(x,y) <= 1800`；非轴向圆域边界点的三角函数浮点溢出若发生，以一个浮点单位内移消除，不允许在圆域外放置源。491000 和 491012 含精确轴向 1800 米点。

## 严重退化的事前理论预期

这些是假设而非观测结果，没有具体退化百分比或性能排名。

- **边界朝外/切向**：源域附近的直进或侧向定位可落在背面，额外检测仍付费；信息收缩不足时最终必须光学覆盖。仅减少光学次数可能掩盖额外移动与检测。
- **单簇/对跖簇 16 源**：改变扫描顺序可能让最后一个频道更晚被发现，取消测站的时机随之延迟；对跖簇还可能产生多次长距离穿越。固定发现骨架也可能错误地推迟有利测站，不能视为保护尾部的保证。
- **两站窗口**：第二站可能没有新方位或两条方位近乎共线；延迟清除仍增加切频/检测。径向源链和低源数案例对该假设较不利。
- **动作入口/出口路线**：实际服务第二探针和光学提前命中位置未知，预测出口可能使下一任务方向错误；模型更复杂不保证整局更快。
- **近场背面**：把距离小于 5 米直接当作 near 或可停止，会造成真实漏检；合法策略仍应按公开无信号保留搜索义务。光学成功须由 clear 响应确认。
- **总数 10**：无法依靠 16 源成功上界提前退出。动态覆盖若撤销测站，必须由连续覆盖证书证明未清除频道已覆盖；若只是插入信息点却仍保留全部扫站，则可能徒增费用。
- **极值误差/舍入半刻度**：若错误依赖同点独立噪声平均，或错误缩小示向度包络，将使区域排除真源；失败必须记为不完整，不能用后处理真值修补策略。
