# 论文组织与方案取舍

建议以新机制候选作为本文的改进算法，以原 BOTH 作为强基线；工程默认仍保留原推荐配置，候选独立运行。原方法的全套入口、路线调度和参数都应保留，否则后续对照容易出现基线漂移。论文核心是“位置可行集合驱动的定位、跨频道信息共享与滚动路线联合决策”，不能只写成改进路线排序。

## 如何呈现创新

1. 共同基础：有界且同点固定的测量误差；保守位置集合；七站覆盖或 16 个成功清除的停止证书。清除和可靠停止优先于速度。
2. 原 BOTH 基线：有保证的第二检测点、固定光学覆盖、已知目标缓存与原路线调度。完整保留其实现及已验证优势。
3. 新方法：新地点观测持续收缩可行集合、随尺度变化的视差选点、保证接收且有收缩价值的跨频道共享观测、将已知目标和剩余搜索站统一安排的滚动路线。最终删除额外的目标原地再观测。
4. 实验解释联合收益：单独中心逼近、视差、共享均未击败基线；加入路线协同后才取得显著改善。最近入口已贡献大部分调度收益，不能把全部收益归因于完整路线优化。

新方案已经吸收原方法的安全基础；不建议再加入“观察到聚集就切回旧方法”的未经验证混合器。最终最差相对退化为 +93.63%，若事后按隐藏布局类别选算法，会引入真值泄漏或验证集选择偏差。混合切换只能作为未来工作，必须另行锁定公开反馈规则、预算与新验证集。
