# 第三问第八轮：当前位置检测可以省路，但不能忽略整局调度

**维持第七轮K推荐版，不升级本轮预先选定的Z。** Z在三个新验证批次均值下降，但外缘舍入压力批均值增加14.58秒，未通过预设门槛。J作为更保守的对照有小幅均值收益，不过没有在选定J之后再生成新案例，不能把它直接当作已完成独立验证的新推荐。

本轮2016局自建实验全部完整清除、停止审计通过，失败/超时/假完成均0；审计239522条动作，93项第三问测试通过。未启动官方exe、官方演练或正式测试，持续优化目标仍在进行。

## 机制、目标和安全条件

原A从16个离散第二点中按费用代理选择，机器人即使已经站在合法第二点处，也未必能直接测量。本轮将当前精确坐标作为额外机会点，不改原目录，不做连续数值寻优或新参数扫描。

将当前位置相对第一观测点的坐标旋转到第一示向度坐标系，逐次调用第二问`candidate()`的完整解析条件：全初始候选范围内保证接收、排除第二点近场退化、最小交角满足20°，误差包络仍为1.005°。只有通过这些条件才考虑原地检测。返回的是当前位置原始坐标，不经坐标往返重建而引入小移动。所有原地测量仍收取5秒检测和必要的1秒切频；不是免费观测，也不做同点多次测量平均误差。

- **J，`current_if_cheaper`**：将当前位置的31×3×3个几何采样场景，与A原有同一费用代理比较。包含5秒检测、最大距离项和光学格数代理，仅在代理费用严格降低时接受当前位置。
- **Z，`current_if_certified`**：只要解析条件成立就用当前位置，消融“费用代理”与“优先零移动”两种取舍。

安全来自解析候选条件和之后的完整光学覆盖，不来自采样直径。采样最坏直径是定位质量代理，不是连续误差上界，更不是给真实源分布设置概率。缓存、数量上限K、七站停止证书保持原规则；策略与HTTP、自建环境分离。Q1/Q2代码、自建误差函数及HTTP接口未修改，新文件为`current_point.py`，接入`modules.py`与公共流程。审计额外验证实际局部坐标满足解析条件，以及原地第二检测的真实移动距离为0。

即使当前位置可行，也未证明它在定位效果或整局时间上最优。Q2原算例的固定偏移不是通用最优，本轮也不把“当前位置”当成新的通用最优点。

## 省移动与定位质量的权衡

普通主批J实际用了58次原地第二检测，分布于53个配置；Z用了242次，分布于141个配置。J从不接受比原目录更高的费用代理，但58次中55次的采样最坏直径更大。Z有196次接受了更高费用代理，240次采样直径更大，最大达到332.49米。外缘Z采样最坏直径可到344.57米。这是允许用移动成本换定位质量的结果，不能把“通过20°交角”理解为“定位质量相同”。实际观测后的候选区可能远小于这个全初始扇区的采样最坏值，仍由真实两次测角生成覆盖计划。

每次机会点记录的`catalog_entry_distance_m`仅表示在同一决策时刻，相对于该源原目录点少走的距离，**不能相加后称为相对整局REF的实际节省**。因为候选起点变成距离0，B可能提前选择该源，第二点还会改变共享缓存的其他频道和之后的路线。

## 关键反例和机制证据

**Z普通主批最坏：`holdout_110035_positive`**。4126.94→4579.30秒，+452.36秒、10.96%。实际检测从104次减少到95次，检测/切频共少54秒；移动却从3415.94增至3919.30秒，多503.36秒，光学多3秒。频道11原地观测的代理费用410.85秒，原目录377.84秒，Z仍接受；J在此例为4081.21秒。不能以检测次数更少证明整局更快。

**Z外缘反例：`outer_holdout_120008_spatial_hash`**。4845.59→5150.42秒，+304.83秒。两方案检测次数、清除次数和光学失败次数完全相同，增加的全是移动。搜索阶段多约307.72秒；两次原地观测后实际光学覆盖都只需一个计划点，这例的净增加来自移动，而非更多清除尝试，不能只用增大的采样直径解释。改变第二点也改变共享缓存和后续任务顺序；该日志支持存在全局耦合，不足以将全部损失归因于单一因素。

**J最坏：`holdout_110019_negative`**。4206.52→4386.64秒，+180.13秒。唯一一次机会选择是频道2，代理仅比原目录好2.61秒；它以零移动起点提前于原版的频道16执行。搜索阶段虽减少约414.16秒，光学阶段却增加约602.36秒，最终移动多183.13秒，失败清除反而少一次。原版与J在此之前的任务序列相同。这为下一轮隔离“零距离改变调度优先级”提供了直接证据。

复用旧反例中，J四例均不变；Z有改善也有退化，主/压力均值各多约3.09秒。所有旧案例仅作开发诊断，不作为新的独立样本。
