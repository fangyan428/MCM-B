# R7 接收边界双侧测距

核心机制：把无线电是否接收到的反馈用作圆形接收边界的成员查询。沿首次方位直线，在首次有信号点两侧二分找到接收圆与直线的两个交点区间；无须知道真实接收半径，两个交点的中点就是源在该直线上的投影。结合首次窄方位楔得到短条带，最后光学覆盖。

已知首次接收距离≤1500、接收半径≤1500，所以两侧3001米均在接收圆外；不需要探测这两个有证明的外点。各侧二分至10米宽，源轴向区间至多10米。所有检测仍逐次真实计费，direction读数不用于缩小区间，near立即清除。不把no_signal当频道不存在；定位完仍沿用原停止证书。

这是独立的可识别性机制，可能因跨越接收圆多次而很慢。配置固定、无参数搜索。BASE和RECEPTION_BRACKET完整对照。
