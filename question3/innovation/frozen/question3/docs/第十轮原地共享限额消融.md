# 第十轮：原地检测后的共享限额消融

结论：保留第九轮 ZL。CS0（原地检测后不额外共享）与 CS1（最多额外共享一个）均未通过预先设定的双误差模型开发门槛。没有生成新验证布局，没有更新推荐配置和历史发布包。不能用 CS0 在主误差下仅 0.81 秒的均值改善宣称优化成功。

## 机制、保证与实验范围

只新增 `current_point_shared_limit` 配置，作用于主目标实际选择合法原地第二检测后的额外共享；普通目录第二点继续最多共享 19 个，搜索、候选区域、接收/夹角保证、光学覆盖与停止证书均沿用原实现。缺省回落到原共享限额，128 局参考组与第九轮 ZL 的完整指标逐项一致。保留 AB、S、1125 米搜索环及 K 数量上界证书。

主误差与舍入压力各使用同一批 52 个开发场景配置（包括误差场，不是 52 个独立布局），再各复用 12 个已知案例；3 方案，共 384 局。配置、源码快照和场景哈希一致性已核查。没有数值扫参；CS0/CS1 只有同时满足两种开发误差下完整清除、均值严格改善、P95 不恶化才能锁定进入新案例测试。两者均不合格，预留的 150000/160000 段种子尚未生成。旧反例已经参与本轮审查，不再称独立验证。

同点检测误差仍固定。策略没有读取隐藏真值；仿真器负责生成观测，评估器事后读取真值复核。原始 `run_matrix` 将所有外部 fixtures 计入 `unseen_validation_cases_run`，本轮复用案例不符合其字段名称；本报告及审查 JSON 明确校正：新增独立验证为 0。

## 对抗检查与结论强度

102 项测试实际通过，包括本轮新增 5 项：原地限额生效且普通批次仍可多目标共享；缓存只测量一次；缺省行为精确回归；晚出现的通道 20 仍完成七站证书；第二点错误无信号必须报告 incomplete；非法配置入场前拒绝（部分合并在同一测试）。原有时限、网络重试、共享中断和证书测试一并实际执行。测试中的本机 HTTP 只连接自建临时端口。

已证明/继承的条件性保证：共享限额不放宽候选资格，跳过共享的目标仍保留在待定位集合，成功清除与七站覆盖/16 源上界证书仍是完整停止条件。只在题面全向、唯一通道、误差范围、最大16源等既定条件成立时适用。

实验支持：本轮所有合法案例完整清除；两项候选缺乏稳定时间收益；默认行为在 128 次参考对照中没有变化。这些有限样本不能证明所有布局都不失败，也不能证明 ZL 是全局最优。

待验证的下一项机制：在光学网格保持原遍历顺序的前提下，只删除其 20 米清除圆与连续候选多边形严格不相交的点。若能用保守几何判定证明被删调用必然失败，则三角不等式可保证跳过其路点不增加移动，且保留原本首次成功点。它与此前 C 的重新排序不同，应先验证“不相交”证书及浮点边界，再做默认关闭的全流程消融。这是候选论证，尚未实现或验证，不宣称已有收益。
